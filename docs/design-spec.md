# 設計規格

- 類型：靜態單頁互動網站
- 技術：HTML、CSS、原生 JavaScript、Canvas、SVG、Web Audio API
- 視覺：深色科技感、青綠與琥珀色作為頻譜重點
- 版面：頁籤式教材架構，支援手機、平板與桌機
- 無障礙：表單標籤、按鈕文字、降低動畫偏好、鍵盤可操作頁籤按鈕

## 聲音譜圖即時描述（2026-09-11）

- 三項數值下方新增整列「音質與音色觀察」，沿用深色卡片與青綠邊線，手機自動換行。
- 每 250 ms 讀取浮點頻譜與波形，最近 6 筆取平均；文字每 750 ms 更新，凍結時暫停取樣與更新，解除凍結後清空歷史。
- `js/sound-description.mjs` 將頻譜 dB 轉為線性功率，分析 60–300、300–2,000、2,000–16,000 Hz 的相對能量、最強峰附近集中度與頻譜平坦度。頻帶比例用於音色，集中度／平坦度用於單純、豐富或雜訊感，近期 RMS 變化用於強弱起伏。
- 這些為教學用啟發式門檻，不是聲源辨識或音質評分；不以主峰直接推斷基頻，不單憑多峰宣稱諧波。忽略 60 Hz 以下與 16 kHz 以上的成分。
- 微弱訊號不保留舊的音色判斷；停止、裝置中斷與權限失敗顯示狀態。圖表訊號超出範圍時提示降低靈敏度，不直接宣稱原聲破音。
- 頻繁變動的描述不設自動朗讀區，避免螢幕閱讀器持續打斷使用者。

## 頻率偵探播放控制（2026-09-11）

- 每題播放 6 秒：40 ms 淡入，維持音量至 5.9 秒，再於第 6 秒淡出結束。
- 「出題」旁加入「停止」按鈕；手機上下排列。準備／播放期間可停止，結束後停用停止按鈕。
- 播放狀態獨立於答題回饋。停止後仍可回答原題；重新出題先停止上一段，使用請求序號防止取消後的延遲啟動。
- 手動停止以約 30 ms 的短淡出避免爆音，音訊結束時斷開節點。

## 猜猜我是誰：62 種真實動物錄音（2026-09-11）

- 保留原有 22 段錄音，新增 40 段不同動物錄音，其中 12 種哺乳類、28 種鳥類。原本顯示「蚊子」的檔案來源為 `buzzing_fly`，校正顯示為「蒼蠅」，不計入新增數量。
- 新錄音以 Commons 的原始檔案說明核對動物與授權。擷取有聲音的短片段，轉為單聲道 MP3、調整音量與短淡入淡出，保留原始速度及音高；40 段共約 3.17 MB。
- `public/audio/bio/manifest.json` 是新動物名稱、分類、檔案、作者、來源頁、授權連結、裁切時間及 SHA-256 的來源；啟動時載入後加入題庫。網頁來源區與 `CREDITS.md` 保留各片段署名與處理方式，衍生片段依原錄音授權散布。
- 載入期間停用出題，失敗可重試。每輪用 Fisher–Yates 洗牌，62 題內無重複，跨輪也避免連續相同答案；四個選項互不重複。
- 保留每次最多 5 秒的動物錄音播放上限及重播；錄音失敗顯示重試提示，移除合成音替代，避免假音混入真實錄音題庫。請求序號防止快速出題產生過期播放或計時器。
