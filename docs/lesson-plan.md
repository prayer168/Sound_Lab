# 教師使用說明

## 建議流程

1. 以「學習任務」說明今天要觀察聲音的三種方式。
2. 使用「頻率產生器」比較 220、440、1000、4000 Hz。
3. 開啟「聲音譜圖」，讓學生拍手、說話或保持安靜，觀察分貝變化，再比較「音質與音色觀察」。用凍結畫面保存當下的頻譜與描述，討論哪些頻率成分支持低沉、明亮、單純或豐富的推估；同一聲源也可能隨發聲方式而改變音色。
4. 在「媒體音頻圖」播放一段音樂，討論低頻節奏與高頻亮度。
5. 使用「聲音遊戲」作為形成性評量。
6. 完成「闖關挑戰」並回看原理與生活應用。

## 安全提醒

請先將裝置音量調低，再播放高頻或掃頻測試。高頻聲不一定每個人都能聽見，不應要求學生長時間聆聽高音量聲音。
