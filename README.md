# 聲音實驗室

一個以 Web Audio API 製作的互動式聲音教材網站，支援頻率產生、麥克風頻譜、分貝觀察、媒體播放視覺化與聲音小遊戲。

## 適用對象

- 國小高年級到國中
- 自然科學、科技、聲音與波動單元

## 學習目標

- 理解頻率、振幅、音高、音量與分貝的關係。
- 使用麥克風與圖表觀察環境聲音。
- 從音樂或影音中辨識頻率能量與節奏變化。
- 透過遊戲練習聽辨低頻、中頻與高頻。

## 主要功能

- 0 到 30000 Hz 系統音頻率產生器
- 聲音譜圖：麥克風即時頻譜、估計分貝，以及隨聲音變動的音質與音色觀察
- 本機音訊、影片與可播放媒體連結視覺化
- 頻率偵探（每題播放 6 秒、可隨時停止）與「猜猜我是誰」（62 種真實動物錄音，新增 40 種，同一輪不重複出題）
- 原理探索、生活應用、逐題闖關與自主學習資源
- 闖關提供答對鼓掌音效、答錯提示音、中文語音回饋、正解標示與全螢幕作答

## 本機啟動

聲音譜圖的三項數值下方會描述低沉／明亮、單純／豐富／雜訊感與音量起伏，約每 0.75 秒更新，凍結畫面時同步保留。描述是頻譜線索的推估，不辨認聲源，也不評分音質好壞。分析在瀏覽器內完成，不上傳收音。

```bash
npm install
npm run start
```

啟動後開啟 Vite 顯示的本機網址。

如果只想直接點開 `index.html`，頁面會自動載入建置後的 `js/app.local.js`，八個頁籤仍可操作。

## 注意事項

- 麥克風功能需要瀏覽器授權，且通常必須在 localhost 或 HTTPS 環境下執行。
- 部分影音平台會限制跨站播放，建議使用可直接播放的音訊或影片檔案連結。
- 分貝數值是瀏覽器端估計值，適合教學觀察，不等同專業校正儀器。
